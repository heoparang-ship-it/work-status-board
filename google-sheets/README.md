# Google Sheets 근태 저장 연결

이 폴더의 `Code.gs`는 업무 현황판의 출근, 퇴근, 외근 기록을 Google Sheets에 계속 쌓기 위한 Apps Script입니다.

## 설정 순서

1. Google Sheets에서 새 스프레드시트를 만듭니다.
2. 메뉴에서 `확장 프로그램 > Apps Script`를 엽니다.
3. 기본 코드를 지우고 `Code.gs` 내용을 붙여 넣습니다.
4. `배포 > 새 배포 > 웹 앱`을 선택합니다.
5. 실행 사용자는 `나`, 액세스 권한은 `링크가 있는 모든 사용자`로 둡니다.
6. 배포 후 나온 웹 앱 URL을 업무 현황판의 `관리자 메뉴 > Google Sheets 근태 저장`에 붙여 넣고 `연동 저장`을 누릅니다.
7. 생성된 `직원 공유 링크`를 직원들에게 전달합니다.

## 기록 방식

- 시트 이름은 자동으로 `근태기록`이 됩니다.
- 첫 행에는 헤더가 자동 생성됩니다.
- 이후 근태 기록은 `날짜 / 사용자 / 출근 시각 / 퇴근 시각 / 외근 시각` 5개 열로 추가됩니다.
- 외근이 여러 번이면 `외근 시각` 열에 쉼표로 구분해 표시됩니다.
- 페이지 업데이트가 있어도 이미 시트에 쌓인 기록은 유지됩니다.

## 참고

정적 GitHub Pages에서는 Google 계정 비밀키를 안전하게 보관할 수 없습니다. 그래서 브라우저가 Apps Script 웹 앱 URL로 기록을 보내고, Apps Script가 Google Sheets에 행을 추가하는 방식으로 연결합니다.
